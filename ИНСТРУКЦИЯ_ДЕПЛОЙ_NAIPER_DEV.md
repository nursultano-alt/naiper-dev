# 🚀 ИНСТРУКЦИЯ: КАК ОПУБЛИКОВАТЬ ПОРТАЛ НА ВАШЕМ ДОМЕНЕ NAIPER.DEV

Поскольку ваш домен **`naiper.dev`** уже делегирован и управляется через **Cloudflare**, у вас есть **бесплатный хостинг Cloudflare Pages**, который деплоит сайт за 1 минуту без серверов.

---

## ⚡ Способ 1: Прямая загрузка папки в Cloudflare Pages (Без Git, 2 минуты)

1. Откройте дашборд Cloudflare:
   👉 **`https://dash.cloudflare.com/`**
2. В левом меню нажмите **Workers & Pages** ➔ **Create application** ➔ вкладка **Pages** ➔ выберите **Upload assets**.
3. Введите название проекта (например: `newyear` или `ny`).
4. **Перетащите папку проекта** `NewYear_Family_Portal` в появившееся окно (либо нажмите *Select folder* и укажите эту папку).
5. Нажмите кнопку **Deploy site**.
   * Сайт *мгновенно* опубликуется в интернете по бесплатному адресу (например: `newyear.pages.dev`).
6. **Привязка к вашему домену `naiper.dev`:**
   * На странице созданного проекта перейдите во вкладку **Custom domains** ➔ нажмите **Set up a custom domain**.
   * Введите адрес, например: **`ny.naiper.dev`** (или основной **`naiper.dev`**).
   * Нажмите **Continue** ➔ **Activate domain**.
   * Cloudflare автоматически настроит DNS-запись и выдаст HTTPS-сертификат.

🎉 **Готово!** Теперь ссылку `https://ny.naiper.dev` можно отправлять в семейный WhatsApp-чат!

## ⚙️ Как пользоваться порталом организатору (Чолпонке):

1. **Вход в кабинет:**
   * В шапке сайта нажать вкладку **«⚙️ Кабинет Чолпонки»**.
   * Ввести пин-код: **`2027`** (или слово `cholponka`).
2. **Настройка расписания:**
   * В форме ввести название события, время начала и длительность (в минутах).
   * Нажать кнопку **«Добавить в таймлайн»** — событие мгновенно появится в плане дня с точным расчетом общего времени.
   * Лишние пункты можно удалять крестиком **✕**.
3. **Управление конкурсом:**
   * Добавлять детей, категорию (до 10 лет / 10–18 лет), костюм и творческий номер.
4. **Резервная копия:**
   * Кнопка **«📥 Сохранить копию»** в кабинете позволяет в один клик скачать файл JSON со всеми актуальными данными.
